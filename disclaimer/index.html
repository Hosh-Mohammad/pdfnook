General

The tools on pdfnook are provided for general convenience, “as is”, without warranties of any kind. While we work to make them reliable, results can vary depending on how a PDF was created.

Document quality and compatibility

Some PDFs use features that browser-based tools cannot fully process (complex forms, unusual encryption, damaged files). Compression modes that convert pages to images remove selectable text. Conversion tools such as PDF to HTML or HTML to PDF are basic text conversions and do not preserve layout or styling. Each tool page describes its limitations.

Security tools

Password protection uses AES-256 encryption, but its effectiveness depends on a strong password that you keep safe. We cannot recover lost passwords. Unlock PDF removes a password only when you provide the correct one; use it only on documents you are authorized to open.

Not professional advice

Nothing on this site is legal, financial or professional advice. If a document is legally or financially important, keep the original and verify the processed copy.
