Frequently asked questions

Can you unlock a PDF if I forgot the password?

No. You need the correct password. This tool does not guess or bypass passwords.

Which encryption types work?

Standard PDF password encryption (RC4 and AES) as supported by the underlying library. If a file fails to open, it may use an unsupported scheme.
