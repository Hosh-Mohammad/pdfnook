Frequently Asked Questions

Is pdfnook really free?

Yes. All tools are free to use, without registration, watermarks or daily limits. The site may show ads in the future to cover running costs.

Are my PDF files uploaded to a server?

No. Every tool runs in your browser using JavaScript. Your documents are never sent to our servers or to any third party.

Do I need to install anything?

No. pdfnook works in modern browsers such as Chrome, Edge, Firefox and Safari on desktop and mobile.

Is there a file size limit?

There is no server limit because nothing is uploaded, but each file is limited to 150 MB to protect your device’s memory. Very large files may be slow on older phones.

Can you unlock a PDF if I forgot the password?

No. Unlock PDF only removes a password when you enter the correct one. It does not crack or bypass passwords.

Which tools work offline?

After the page has loaded once, most tools keep working without an internet connection because everything runs locally.
